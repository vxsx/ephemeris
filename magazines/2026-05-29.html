A 750,000-line port, done in eleven days.

Claude Code's dynamic workflows orchestrate tens to hundreds of subagents in one session — splitting a job into subtasks that run in parallel, verifying each result before merging. Jarred Sumner used it to port Bun from Zig to Rust at 99.8% test compatibility. Work you'd plan in quarters now finishes in days; progress survives interruptions.

Ephemeris · Issue 041 03 / 05 · Cloudflare
Infrastructure · Data Platform

From days to three seconds, in plain English.

Cloudflare's Town Lake puts one SQL interface over Postgres, ClickHouse, BigQuery, R2 and Kafka via Trino and Iceberg. On top sits Skipper, an agent that turns a plain-English question into validated SQL. It fields over a billion events a second across 330+ cities; in one window, 324 employees ran 91,760 queries — most answered in three seconds, not days.

"All access should be auditable, with time-bounded permission grants — you reach the data only while you're actively working on it."

Ephemeris · Issue 041 04 / 05 · Sentry
Engineering · Build Performance

Fourteen minutes to four, by deleting the CMS.

Sentry's marketing-site builds were collapsing under a headless CMS — Gatsby-plugin crashes and rate-limited API calls, several failures a day. They tore it out for Astro, Markdown with frontmatter, and Claude-driven content skills. Builds fell from about 14 minutes to under four — roughly 15.8 hours of CI reclaimed every day.

After<4 min
