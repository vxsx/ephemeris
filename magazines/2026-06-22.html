Do it once. Codex replays it forever.

Record & Replay, which shipped June 18 for the macOS Codex app, watches you finish a repetitive task one time, then drafts an editable SKILL.md — when to use it, what inputs it needs, the steps, and how to verify the result. Unlike screen-recorder RPA it captures intent, not pixel coordinates, so it adapts when the interface shifts.

# SKILL.md  ·  drafted from one demo
name: file-monthly-expense
use_when: a receipt PDF lands in ~/Inbox
inputs: [ receipt, month ]
steps:
  1. open portal · 2. attach {receipt}
  3. set period {month} · 4. submit
verify: confirmation id is shown

A 1993 game, rebuilt to the byte.

Denis Sergeev reconstructed the Russian DOS show Поле Чудес from its compiled binary into TypeScript — sprites, CP866 bitmap fonts, the question dictionary and scoring table — leaning on Claude Fable for roughly $100 in API. Every transcoded asset reverse-encodes back to the original, sha256-pinned in the test suite.

56,528.exe bytes, decompiled
61 RLE sprites → lossless WebP
3 CP866 fonts → glyph atlases
1 scoring table → JSON

Give the whole team a chief of staff.

TeamOS is a starter toolkit that pairs a shared institutional-knowledge repository with AI agents, aiming at team output rather than individual speed. The bet: capture the memory and routines a chief of staff would hold, make them queryable, and the agents stop re-asking what the team already decided.

Decisions

Why a call was made, and what it ruled out — so agents don't relitigate it.

Playbooks

The repeatable steps for onboarding, releases, incidents, kept where agents can run them.

Context

Customers, constraints, current bets — the standing brief every new task starts from.

Routines

Recurring chores handed to agents against the shared record, not a single person's memory.
