Ephemeris · Issue 079 02 / 5 · Vercel
Dev infra · Agents

Give the sandbox a filesystem that isn't there.

Vercel Sandbox now mounts FUSE-based filesystems, so the ephemeral box you drop an agent into can read from a virtual or remote source instead of a disk baked in at build time. For anyone running untrusted agent code, the working directory can be assembled on demand and thrown away with the box.

FILESYSTEM   fuse (user-space mount)
MOUNT        on-demand, per invocation
BACKS ONTO   virtual / remote source
LIFETIME     dies with the sandbox

We tested caveman talk. It saves 8.5%.

The viral "talk to your agent like a caveman" skill promised 65% fewer tokens. JetBrains ran it across 82 paired SkillsBench tasks and measured 8.5% on real agentic coding, with no detectable hit to quality. What dominates an agent session is code and tool calls — and the skill leaves those untouched.
