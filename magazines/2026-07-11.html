Better tools made the code review worse.

GitHub handed Copilot's reviewer the same Unix-style grep/glob/view tools its CLI uses — and quality dropped, because generic instructions sent the agent wandering the whole repo instead of reading the diff. The fix was the prompt, not the toolbox: start from the diff, narrow the evidence, open files only when needed. Reviews came out about 20% cheaper at the same quality.

An image model that edits like a designer.

ByteDance's Seedream 5.0 Pro brings point-, lasso-, and material-level control to text-to-image: mark a region and it changes only that region, leaving the rest coherent. It also splits a scene into ten-plus transparent layers you can drag and recompose, and renders text across a dozen languages — Spanish accents, Arabic script, and all. The output stops being a flat picture and starts being a file you can open.

Ephemeris · Issue 082 04 / 6 · DeepSeek
Research · Inference

Same answers out — up to 85% sooner.

DeepSeek open-sourced DSpark, a speculative-decoding framework that drafts tokens with a small parallel model and verifies them in a single pass on the big one — 60–85% faster per user on V4, with a scheduler that verifies more tokens when GPUs sit idle. The acceptance rule preserves the target model's distribution, so the output is statistically identical to plain decoding. The training code, DeepSpec, ships MIT-licensed.

Ephemeris · Issue 082 05 / 6 · Cursor

Chase the tangent without dropping the thread.

Cursor 3.11 adds side chats — a parallel conversation next to your main one, so you can test an idea or ask a throwaway question without derailing the agent already at work. It also searches past agent transcripts by what was actually said, not just their titles, and scopes the project and repo pickers so you land in the right place faster.

Ephemeris · Issue 082 06 / 6 · Cloudflare
Infrastructure · Caching

Cache that parks next to your origin.

Cloudflare's Smart Tiered Cache now takes a hint about where your origin actually lives — an AWS, GCP, Azure, or Oracle region — and picks an upper-tier data center close to it. Fewer long hauls back to origin on a miss means lower latency and less egress on the requests that get through. It's a one-setting change for anyone serving from a public cloud.
