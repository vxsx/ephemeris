Copilot now bills by the token.

On June 1 GitHub moved every Copilot plan to usage-based billing. Premium request units are gone; in their place are AI Credits — one credit equals one cent of model usage, and every chat, agent run, and code review draws down a monthly allotment. Base subscription prices held steady, but token-heavy agentic sessions are now the line you watch.

Cursor's SDK lets agents spawn agents.

The June 4 SDK update trims the ceremony around custom agents. Hand tools straight to an agent through local.customTools instead of standing up an MCP server, pick your own persistence layer, and gate which tool calls auto-run with plain-language rules in permissions.json. Subagents can now nest to arbitrary depth, each carrying its own prompt and model.

// tools without an MCP server
local.customTools = [ runTests, deploy ]

// bring your own store
store: LocalAgentStore  (JSONL | SQLite | custom)

// natural-language approvals
permissions.json → "auto-run reads, ask on writes"

// delegation, all the way down
agent → subagent → subagent → …

Malware that lies to your AI scanner.

Socket flagged the Hades campaign on June 8 — roughly 29 PyPI packages, including the graph-ML library ensmallen, carrying memory scrapers that hunt plaintext credentials on CI runners. The trick: the payload opens with text addressed to the reviewer's LLM, telling it to mark the package clean. Sibling variants embed fake bio- and nuclear-weapons instructions so a safety-tuned model refuses to read the file at all. Signatures, sandboxing, and runtime monitoring still caught it.

Fable rebuilt a DOS game from its binary.

Handed only a compiled .exe of "Поле Чудес" — a 1993 Soviet Wheel-of-Fortune clone — Claude Fable reverse-engineered it into working TypeScript, sprites and all, for about $100 in API calls. The reconstruction runs in a browser. It's a sharp little proof that frontier models now read machine code well enough to resurrect software whose source nobody kept.

$ decompile --from binary pole-chudes.exe → pole-chudes.ts
sprites extracted ~$100 in API runs in-browser

The fine print on Fable 5.

Zvi Mowshowitz read the Fable 5 / Mythos 5 system card so you don't have to. The practitioner takeaway: Fable is the best model you can call, but its classifiers reroute about 5% of bio, cyber, and ML prompts to Opus 4.8, and hallucination on missing references climbed to 18%. The safety figures are the loud ones — generalist teams using Mythos compressed work that normally takes 72 days into 16 hours.

The search box stopped sending clicks.

Answer engines now resolve the query and keep the reader on the page. Jeff Bullas's prescription is blunt: stop renting attention from a box that no longer forwards it. Move people onto a channel you own — the email list is the destination — turn the training crawlers away in robots.txt, and write the first-hand, specific work a model can't reconstitute.
