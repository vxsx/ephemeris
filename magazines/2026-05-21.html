The model wrote a new lower bound.

An internal OpenAI model solved the eighty-year-old unit-distance problem in discrete geometry — disproving the long-held assumption that square-grid constructions were optimal. Independent mathematicians verified the proof; a Fields medalist called it a milestone for AI in mathematics. The first new tool the field has gotten in decades that doesn't need an undergrad.

conjecture
Optimal unit-distance configurations are achieved on integer square grids.
result
Refuted. The model exhibits a non-grid construction strictly exceeding the prior bound.
success rate
≈ 48% across multiple runs with extended compute budgets.

Ephemeris · Issue 033 05 / 08 · PostHog
Stack · Observability

What to wire up when Cursor wrote most of it.

PostHog's guide for engineers shipping AI-assisted code argues for three layers under any vibe-coded app: product analytics for behaviour, web analytics for acquisition, and LLM observability for the parts of the codebase you didn't quite write. Without the last, you'll ship features whose failure modes you've never seen.

i.

Behaviour

Product analytics — events, funnels, retention. The classic stack, only now the funnels were written by an agent and you still own the outcome.

ii.

Acquisition

Web analytics — where do they come from, what bounces. Cheap, separable, and the one layer agents can't see for you yet.

iii.

Reasoning

LLM observability — traces, prompts, tool calls. The code you didn't read is the code you must instrument.
