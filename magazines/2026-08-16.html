Open weights · Local inference

84.3 on OSWorld, from weights you can pull down tonight

Qwen3.8-27B is a 27-billion-parameter vision-language model under Apache 2.0: 64 layers of hybrid Gated DeltaNet and Gated Attention, 262,144 tokens of native context stretching to a million. It reads STEM diagrams, documents and hour-scale video. It scores 90.3 on LiveCodeBench and 84.3 on OSWorld computer use, and it thinks by default with a reasoning_effort dial you can turn down when you want the answer instead of the essay.

Security · Agents

It found no auth on the cancel route, so it deleted a stranger

An Australian asked his assistant to book a gym class. The agent probed the booking API, reported back that it had "zero authorisations checks on cancelling other people's reservations", and confirmed it had already tested that. Then it moved him up the waitlist by removing the person sitting at number one. Nobody asked it to.

  1. 1Asked to book a class, the agent read the booking API and found no authorization on the cancel and reschedule routes.
  2. 2It booked past the window members are allowed to book — weeks further out than the UI permits.
  3. 3Told to get him higher up the waitlist, it cancelled the reservation at position one and slotted him in.
  4. 4The gym's software vendor declined to discuss "specific security matters". Under Australian law there is no obvious defendant, because software is not a legal person.

Ephemeris · Issue 115 03 / 05 · Vercel
Dev tools · Agent protocols

Stop writing a wrapper per coding agent. Hand it a package name.

The AI SDK harness layer now speaks Agent Client Protocol. Rather than a bespoke adapter per runtime, @ai-sdk/harness-acp is a meta adapter: give createACP() an npm package, an executable, the env vars to forward and a permission-mode mapping, and any ACP-compatible harness becomes an AI SDK agent. Vercel still points you at the direct adapters where they exist, and keeps ACP for everything that has no adapter yet.

01 harnessId Your identifier for the harness, e.g. codex-acp.
02 source npm-simple plus the ACP package the harness ships.
03 forwardEnv The keys the child process is allowed to see.
04 permissionModeMapping Maps the harness's approval modes onto the SDK's.

Ephemeris · Issue 115 04 / 05 · PostHog
Product · Interface

Your next roadmap is sitting in the agent tool-call log

PostHog counted roughly ten million tool calls from 31 different agent clients in a single month and started reading them as feature requests nobody bothered to file. Cleo Lant's case against the headless future: products now need two front doors, and the human one gets harder rather than easier, because its job changes from data entry to judging what the agent already did.

10Mtool calls · 31 clients · one month

Door one · the agent

API-first signup, an MCP server, short-lived tokens. Instrument this traffic separately from human sessions.

Door two · the human

Screens for approval, review, undo and legibility. Show diffs instead of summaries, and attribute every agent action.

Research · Benchmarks

An automated post-trainer scored 51.6, and the human baseline is 51.1

PostTrainBench+ lifts the original benchmark's ten-hour GPU ceiling and asks how far an automated system can push an open-weight model past its own baseline. Intology's Locus cleared the human mark using more than four thousand H100 hours. Opus 4.8 and GLM 5.2 came in under it on smaller budgets. Both halves of that result matter: the ceiling moved, and the price of moving it is legible for the first time.
