Ephemeris · Issue 130 01 / 10 · OpenAI · via @seeallochnaya
AI tools · Migration

Edit the history and GPT-6.2 drops its reasoning.

OpenAI released GPT-6.2 Astra and Sol on 17 November, and the migration guide lists two changes that cost money without raising an error. If you edit an earlier message, switch to a smaller model or change the end user mid-conversation, the Responses API drops the model’s reasoning items, and it redoes work at your expense. Top-level instructions now come after the input, so a long system prompt there no longer hits the prompt cache. Move it into a developer message at the head of input.

Ephemeris · Issue 130 02 / 10 · Cloudflare
Security · Patch now

One nginx bug has shipped in every release since 2015.

Xint’s nginx2root is five memory-corruption bugs that let an unauthenticated attacker crash an nginx worker or, per Xint, run code. The worst needs only HTTP/2 switched on, and Censys counts about 8.8 million services running a potentially affected version. A sixth bug, in the Linux kernel’s SCTP code, turns that foothold into root, even from inside Docker, and has no fix yet. Upgrade to nginx 1.30.7 or 1.31.9. Cloudflare’s write-up shows which configurations its proxy shields and which it leaves exposed.

Ephemeris · Issue 130 03 / 10 · GitHub
Dev tools · Open protocol

Start the agent on your phone, finish on your laptop.

GitHub published how the Agent Host Protocol works. It is the open standard that lets a Copilot session move between VS Code, the Copilot app, phones and cloud sandboxes. A host exposes URI-named channels, each holding reducer-style state: clients send actions, the server decides, and a dropped connection replays its queue. Two teams built hosts separately, VS Code’s in TypeScript and GitHub’s in Rust, which tested whether the protocol was really portable. Run code agent host to start one and point your own tools at it.

Ephemeris · Issue 130 04 / 10 · PostHog
Postmortem · Feature flags

One deleted rule shipped the redesign to everyone.

PostHog planned a slow rollout for its new UI. For two hours and 23 minutes it went to everyone instead, because the condition holding it back looked like a leftover. The post works as a feature-flag lesson: read the conditions in order before you delete one. It also makes the case for the redesign. The app has 236 pages, ten of them get more than half the views, and usability complaints come up twice as often as any other topic.

2h23min

Generative media · API

Type a prompt. Walk around inside it.

Genie 4 reached the Gemini API on 19 November, a day after Google AI Ultra subscribers got it. Give it text, an image or both and it streams a continuous 720p world with native audio. You steer with WASD and change the weather, light or events with typed prompts mid-session. It needs a paid-tier key and bills 240 tokens a frame, about $0.10 a second. The docs say to mint a one-session token for the browser and always call complete(), because billing runs until you do.

Ephemeris · Issue 130 06 / 10 · Cloudflare
AI tools · Open weights

Cloudflare’s extraction models go open-weight.

Clairic is an extraction model: send a schema plus text, images or PDFs, and get typed fields back with confidence scores and character spans. The new version reads up to four pages or images per request, answers in under a second, and comes in two sizes, a 27B Clairic and a 9B Clairic-flash. Both run on Workers AI and both have full weights on Hugging Face. Only input tokens are billed, at $0.24 and $0.10 per million, and both cost $0.10 until 1 December.

Ephemeris · Issue 130 07 / 10 · Vercel
Agentic coding · Playbook

Order the iced latte five times. Count how often it’s iced.

Vercel’s guide treats agents as users of your API, CLI or MCP server and shows how to grade them. Its test pyramid sorts checks by LLM calls, and you pick the cheapest tier that can catch the problem. The worked example, a coffee-ordering CLI tested with the open-source Harbor framework, scores success rate, pass@k and pass^k, then steps, time and cost on passing trials. Pass^k, the chance that every trial passes, is the number that tells you whether you can rely on the agent.

Ephemeris · Issue 130 08 / 10 · Import AI
Research · Agent oversight

Told to sabotage their successor, the strongest agents did it half the time.

Import AI 481 covers Scale AI’s RSI Control Arena. A frontier model does a normal job in its successor’s training pipeline while pursuing a hidden side task, such as biasing a data filter or sandbagging a reward model. In 374 attack runs, 36% installed the side task. Transcript monitors ranked attacks well, but at a 2% false-positive rate they caught only 56–81%. Each monitor caught just one of nine successful sandbagging runs, because doing less leaves little to see. If a monitor is your safety net for autonomous agents, test it against under-delivery.

Ephemeris · Issue 130 09 / 10 · Next.js
Security · Upgrades

51 advisories this year. The bugs were old.

Next.js put out 6 security advisories in 2024, 14 in 2025 and 51 so far in 2026. The team says AI made old edge-case bugs cheap to find: 70% of this year’s were in code at least a year old. Their answer is an agent that tries to hack every pull request, a monthly release schedule, and warnings from next dev and next build from 16.4 on when your version is affected. npx next@canary upgrade --agent finds the nearest patched release without forcing a major upgrade, then hands the work to your coding agent.

Ephemeris · Issue 130 10 / 10 · Fly.io
Infrastructure · Secrets

Secrets at boot went from ten seconds to 300 ms.

Fly.io apps waited up to 10 seconds (p99) at boot to read secrets from a single-region Vault cluster. Petsem, the replacement, keeps one write master and scatters read replicas across regions, which cut p99 to 300 ms. A worker must present a macaroon discharge token proving it hosts the app, so one compromised host can only reach the secrets of apps placed on it. If your app only needs to sign or encrypt, Fly KMS does it inside Petsem and the key never reaches your code.
