778 folds, none of them rehearsed

Sunday Robotics put ACT-2 into homes it had never trained on and asked it to fold laundry. Across 778 evaluated folds and nine garment types it succeeded 99.1% of the time, zero-shot, with no per-home tuning. The claim worth arguing with is the second one: the team says a single fine-tuning example was enough to teach a new behaviour that then generalised to unseen environments.

Your landing page is now a flight path

scroll-world is an agent skill that takes a brand and builds the whole scroll-scrubbed Apple-style flythrough: it generates a set of isometric diorama scenes, renders a continuous camera flight between them, and ships a portable JS engine that pins playback to scroll position. Opened 6 July, 7.2k stars by the end of the month — the interesting part is that the deliverable is a pipeline, not a template.

Pipeline
scenes → isometric dioramas, one per section, style-locked
flight → camera path rendered between scenes as video
engine → playback scrubbed to scrollTop, portable JS
repo → 7.2k stars · 800 forks · 19 commits

Voice agents · Case study

Thirty thousand shoppers, and the counter never shut

avatarin built a 24/7 multilingual retail agent on GPT-Realtime and put it in front of Yamada Denki customers. Thirty thousand people used it in the first two weeks and 92% of survey responses came back positive. Worth reading as a deployment shape rather than a demo: what a real-time voice agent has to cover when the shop is open and nobody is behind the desk.

FROM: a consumer-electronics floor in Japan

STACK: GPT-Realtime, speech in and out, multilingual by default

SHIFT: round the clock, no queue, no closing time

NOTE: two weeks is early — but it is a real till, not a pilot deck

Now the adoption data answers back

The Anthropic Economic Index has been a dataset you downloaded. It is now a connector you switch on from the menu in claude.ai, and then ask questions of in plain language — which occupations lean on the model, how usage splits by region, which tasks look like automation versus augmentation. The caveat is stated in the post and matters when you quote it: this measures Claude conversations, not the labour market.

# Ask it about What comes back
A1 Occupation adoption rate by job family
A2 Region usage mix, state by state
A3 Task automation vs augmentation split
A4 Time trend across index releases
