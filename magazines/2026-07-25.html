Ephemeris · Issue 095 02 / 05 · Cloudflare
Networking · Routing

Seventy percent of your routes arrive edited.

Cloudflare measured what transit providers do to the BGP ORIGIN attribute in flight and found roughly 70% of observed paths come back rewritten. Resetting ORIGIN to IGP hands the rewriter 18% more IPv4 paths and 40% more IPv6 — a thumb on the scale four steps down in route selection. Iliana Xygkou and Bryton Herdes argue the attribute should stop deciding anything at all.

Direct peers rewriting ORIGIN to IGP~10%

The image model shipped with nothing to check.

Qwen-Image-3.0 arrived on 21 July aimed squarely at work: 4,500-token prompts, text claimed legible down to 10 pixels, twelve native languages, UI mockups and document layouts instead of portraits. It came through the chat interface only — no downloadable weights, and none of the technical report that shipped with 1.0 and 2.0 under Apache 2.0. Alibaba's own sample reel is the whole evidence base a developer gets.

Ephemeris · Issue 095 04 / 05 · PostHog
Data · Agents

One DuckDB per tenant, awake in 300ms.

PostHog's "context warehouse" pitch is a warehouse an agent can query without an ETL pipeline in front of it. Strip the positioning and there's a real shape underneath, and it is worth copying: a DuckDB instance per organisation in a Firecracker microVM over S3, waking from idle in roughly 300ms, exposed on the Postgres wire protocol so an agent reaches it through MCP with no bespoke connector.

Ephemeris · Issue 095 05 / 05 · Claude Help · via @rvnikita_blog
Workflow · Automation

Show it once. It writes the skill.

Cowork in Claude for Mac now builds a skill from a screen recording. Hit record, do the task the way you always do it, narrate as you go, and Claude turns screen, clicks, keystrokes and voice into a skill definition you review before saving. That replaces the part of automation everyone stalls on: writing down steps you only know by doing.
