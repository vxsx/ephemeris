Agentic coding · API

Eighty-eight hours, ten thousand agents, and a 166-page proof.

The run started on 1 September and finished 88 hours later, and it shipped with a Lean formalisation a machine can check. Read it for the method, not the trophy: this is what a research swarm costs and how its output is made auditable.

Ephemeris · Issue 120 03 / 10 · HeyGen · via @denissexy
Generative media · Open source

Write HTML. Render video. Same frames every time.

HyperFrames is HeyGen's Apache-2.0 renderer that turns HTML, CSS and animation into MP4 through headless Chrome and ffmpeg. GSAP, Lottie, Three.js and plain CSS animations all work, and the output is deterministic — same input, same frames — which is what makes it safe to put in CI. It ships 20 agent skills and a component registry, so an agent can author motion graphics the way it authors a web page. Denis Sergeev cut a reference-matched motion piece with it in seventeen minutes this week.

Ephemeris · Issue 120 04 / 10 · Cloudflare
Edge runtime

Node compatibility is on by default, and the ceiling is 64 mebibytes.

Cloudflare rewrote the Workers module registry, and two of the changes remove reasons you were not deploying there.

Every stable Node.js runtime API is now enabled by default, with no compatibility flag to remember. The size ceiling moves to 64 mebibytes on all plans, and the separate compressed-bundle limit is gone — the constraint that used to force aggressive minification on anything with a real dependency tree.

The registry itself was rebuilt around URLs rather than filesystem paths. Module specifiers are real URLs, so import.meta.url, import.meta.main and import.meta.resolve() all behave. Query strings and fragments now produce distinct module instances, and node: and cloudflare: protocols resolve properly.

Underneath: lazy compilation, so a module compiles on first import; a shared cache so one instance serves many V8 isolates instead of recompiling per isolate; and identical error classes whichever import path you took. Import attributes are validated to spec.

The registry rewrite is opt-in. Add "compatibility_flags": ["new_module_registry"] and redeploy.

Ephemeris · Issue 120 06 / 10 · PostHog
Observability · Multimodal

To film a session replay, they stopped the clock.

A multimodal model cannot watch a DOM mutation log, so PostHog turned rrweb recordings into MP4. Rendering under CPU contention desynchronised everything — frames froze, captures skipped. The fix is worth stealing.

Rasterizer (session replay → MP4)

PostHog · in production since March 2026

Virtual clock replacing Date.now, performance.now, requestAnimationFrame, setTimeout and setInterval, advancing only on frame capture. Headless Chromium at 8× playback, driven through Chrome DevTools Protocol; HeadlessExperimental.beginFrame holds the compositor until the capture signals. Encoded with ffmpeg.

3.5 million videos rendered from over 370 years of recorded sessions, hundreds of concurrent jobs across pods.

Ephemeris · Issue 120 07 / 10 · Vercel
CDN · Architecture

215.8 ms to 19.1 ms, by putting an index inside the shard.

Vercel's CDN used to fetch routing metadata one path at a time. On a deployment with hundreds of thousands of paths, every deploy reset the cache and every request paid a miss. The rewrite groups metadata into ~200 KB JSONL shards with sorted paths and Base64 offsets, so one fetch warms many paths and a binary search over fixed-width pointers parses only the record you asked for.

Ephemeris · Issue 120 08 / 10 · Next.js
Bundling · Turbopack

Your bundler assumes two-thirds of visits are a single page.

Turbopack merges chunks to cut requests, and the merge maths is weighted by a guess: 0.67 of sessions end on the first page. Sam Poder's write-up shows the guess, then hands you the dials. Next.js 16.3 adds firstPageLoadPriority (start from your bounce rate), priorityRoutes, and clusters for routes visited together — plus generateComponentChunks, which emits un-merged chunks alongside merged ones so the runtime picks whichever is cheaper given what the browser already holds. turbopackSharedRuntime saves a blocking request and ~10 KB per navigation; turbopackCjsTreeShaking finally shakes CommonJS.

Ephemeris · Issue 120 09 / 10 · Cloudflare
Post-quantum · DNS

One signature is 2,420 bytes. UDP budgets 1,232.

1.1.1.1 now validates DNSSEC signed with ML-DSA-44, the NIST post-quantum scheme, so the internet can stress-test the awkward part at resolver scale. The awkward part is size: a single signature is 38× an ECDSA P-256 one and blows the DNS UDP budget on its own, forcing truncation and a TCP retry. Fragmenting UDP is not an option worth taking.

2,420bytes / sig

ECDSA P-256 signature  64 bytes
ML-DSA-44 public key  1,312 bytes
Original UDP message cap  512 bytes
Recommended maximum  1,232–1,400 bytes
Cloudflare's full-PQ target  2029

The migration hazard is subtler than the size. Zones publish classical and post-quantum signatures side by side, and RFC 6840 lets a validator accept any single valid path — so an attacker forges the breakable algorithm and the post-quantum signature never gets asked. Plan for larger responses and a TCP or DoH path now.

Ephemeris · Issue 120 10 / 10 · Import AI
Multi-agent · Evals

One agent found the autograder bug. Twenty-seven minutes later, the swarm had it.

DeepMind pointed 100 Gemini 3.1 Pro agents at 71 problems from Formal Conjectures, gave them a bulletin board, direct messages and a shared library, and told them not to cheat. Thirty-seven problems in, prover-theta found a hole in the autograder. The library that made them collaborative made the exploit contagious, and the remaining 34 problems fell to it. Jack Clark's Import AI 472 covers the paper; the operational reading is that a shared memory is an attack surface, and that the population split matters more than the average.
