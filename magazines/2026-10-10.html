Ninety open problems, one GitHub drop.

On 6 October OpenAI posted 722 manuscripts from an unreleased internal model, grouped into 372 results that include claimed progress on 90 of the 500 best-known open problems in mathematics. Zvi Mowshowitz collects what mathematicians make of it, from Strogatz and Kontorovich to the advisory group that had asked labs to keep such problems off private models. The practical lesson sits in the error log: 42% of the papers come with Lean proofs, and all three withdrawals so far are in the unformalized rest.

Ephemeris · Issue 124 03 / 10 · Cloudflare

The model never fetches its own evidence.

Cloudflare’s Managed Defense team published the harness behind its alert triage. Deterministic code collects and versions the evidence before inference starts, four specialist agents must cite items from that package, and application code throws out any citation that is missing, out of scope or doesn’t back its claim. If you are building an agent whose output a human has to sign, this is the shape to copy.

Ephemeris · Issue 124 05 / 10 · GitHub
Dev infra · Architecture

A push is only as fast as the slowest replica.

Agents commit after nearly every action, and GitHub counted 7.38 billion commits in September, five times as many as a year earlier. Each repository lives as five full copies on fileserver disks and every copy takes part in every write, so adding read capacity makes pushes slower. Brian Celenza lays out the rebuild: the authoritative copy moves to Azure Blob Storage, reads come from cache workers, and only the ref update needs agreement. Internal benchmarks show up to 35× the write throughput.

Ephemeris · Issue 124 07 / 10 · Sentry
Dev tools · Observability

$tracing that survives the bundler█

Sentry’s JavaScript SDK v11 stops monkey-patching module exports through OpenTelemetry loader hooks. It injects diagnostics_channel calls into library source while your app is built or loaded. Isaac Z. Schlueter explains why the old chain broke: it needed a live Node loader and a package.json on disk, and a bundle on Vercel, Netlify or Workers has neither. The same transform now traces Cloudflare Workers, Bun and Deno.

Ephemeris · Issue 124 08 / 10 · Next.js
Dev tools · Frameworks

One line fails the build if a page goes dynamic.

Next.js 16.4 recommends Cache Components for every app, switches them on in create-next-app, and will make them the default in Next.js 17. The new ensureStatic export fails the build when a dynamic component ends up in a route you meant to keep static. For existing apps, npx next@canary upgrade --agent=latest hands your coding agent version-specific migration steps.

Ephemeris · Issue 124 09 / 10 · PostHog
Agentic coding · Infra

Nothing that matters lives only in the sandbox.

PostHog runs every cloud agent it ships, from the Slack app to self-driving bug fixes, through one runtime. A Temporal workflow owns the run, a Modal VM with a real kernel and Docker does the work, and snapshots bring a dead box back with the conversation and working tree intact. The safety section is the one to steal: an LLM judge blocked 1,374 suspicious signals in one week, and PostHog still put a network allowlist under it, because a judge eventually waves something through.

TO
anyone running agents in the cloud
FROM
PostHog engineering
RE
five things a run has to do
CC
whoever is on call
  1. Survive its own infrastructure. State lives in Temporal, so a deploy can’t kill a run.
  2. Take messages at any time. Follow-ups queue in order; re-sent webhooks are dropped by id.
  3. Be safe. A judge screens inputs; the VM can reach at most 100 allowlisted domains, no raw IPs.
  4. Be a real machine. A VM with Docker, booted from a warm pool while you type.
  5. Distrust its own build spec. The repo token is removed before your setup commands run.

The DNS root changes its key tomorrow.

On Sunday 11 October the root zone switches its key-signing key for only the second time, from KSK-2017 to KSK-2024. A validating resolver that never learned the new key will fail DNSSEC checks for names under every top-level domain. On 1.1.1.1 or Cloudflare DNS there is nothing to do; if you run your own resolver, Cloudflare’s post shows how to ask it directly with two queries.

OUTKSK-2017 · key tag 20326 · signing since 2018 INKSK-2024 · key tag 38696 · in the root DNSKEY set since 11 Jan 2025

Same algorithm, RSA/SHA-256. KSK-2017 is revoked in 2027 and its private key is scheduled for deletion.
