Ephemeris · Issue 052 02 / 6 · Sentry Engineering
Dev tools · Debugging

Hand it the issue,
get a repro._

Sentry's SDK team wired a Claude skill to the worst part of triage — building a minimal reproduction. Feed it a GitHub issue, it picks the right language, framework and SDK versions and opens a PR with steps. They stopped short of full automation so the bot wouldn't drown maintainers in noise.

sdk-team@sentry:~$ repro https://github.com/getsentry/sentry-javascript/issues/4821
→ parsing report… next@16.2 · @sentry/node 9.x · node 22
→ scaffolding minimal app + failing route
→ confirmed: span dropped on edge runtime
✓ opened PR #4822 — "repro: missing span, edge runtime"

Block the actor,
not just the request.

Cloudflare opened its Cloudforce One threat intelligence as new cf.intel fields you can write straight into WAF rules. Match on the threat actor behind a campaign — or the industry it's targeting — and block in real time, instead of waiting for the next managed-ruleset update.
