Inference · Serving

Write the model once, serve it fast.

For years, making a model quick in vLLM meant keeping a second, hand-tuned copy of it alongside the Transformers one. The new modeling backend closes that gap: pass --model-impl transformers and dynamic layer fusion gives any compatible model native vLLM throughput. Across Qwen3 at 4B, 32B and a 235B MoE, the single implementation meets or beats the hand-written version. One file to keep in sync instead of two.

On-device · Web AI

Ship the model to the browser, not the server.

LiteRT.js drops Google's native inference runtime into the browser through WebAssembly and WebGPU, so a model runs entirely on the user's machine — no server round-trip, no upload of their data. The demo runs real-time object detection with Ultralytics YOLO. If you've been paying to host inference that could live on the client, this is the week to move it.

Ephemeris · Issue 083 03 / 04 · Mistral AI
Leanstral 1.5 · Apache-2.0 Formal methods · Open models

A machine that shows its proof.

Leanstral 1.5 is an open model built for one job: writing machine-checked proofs in Lean 4. At 119B total but only 6B active parameters, it saturates miniF2F and clears most of PutnamBench. The practical payoff is verification that catches real defects — the team used it to surface five previously unknown bugs across 57 open-source repositories, with weights and a free API within reach of an ordinary project.

Ephemeris · Issue 083 04 / 04 · Google Developers
Infrastructure · Training

We killed a TPU mid-run. It recovered in two minutes.

Train on enough chips for long enough and hardware will die on you; the usual answer is to tear the whole job down and reschedule. MaxText's elastic training turns a dead TPU into a caught Python exception — PathwayS flags it, an elastic_retry decorator reloads the latest Orbax checkpoint onto surviving chips, and the run continues on the slice that lived.

# 48 chips · 3 slices · Qwen3-0.6B · ~$30 / 30 min

✗ slice-2 lost — hardware fault raised as exception
elastic_retry: reload Orbax checkpoint → surviving chips
