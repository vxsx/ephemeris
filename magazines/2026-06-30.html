The build engine keeps its memory between runs.

Turbopack in Next.js 16.3 writes a persistent on-disk cache, so a cold build reuses work it already did instead of starting over. It also evicts dev-server memory before it balloons and ships an experimental Rust port of the React Compiler. The slow half of the loop — recompiling what never changed — gets shorter.

They tore out ClickHouse and rebuilt on DuckDB.

PostHog rebuilt its data warehouse on DuckDB, handing each customer a single-tenant instance and first-class support for dbt and the modern data stack. The post is the reasoning worth stealing: why an engine that began life embedded in analytics apps won the warehouse workload over a distributed column store.

Ephemeris · Issue 071 03 / 05 · Vercel
AI Tools · Realtime Voice

Voice becomes a primitive, not a project.

Vercel's AI Gateway now speaks. Realtime models from OpenAI and xAI sit behind one API, with generateSpeech() and transcribe() for one-shot work and a useRealtime hook for the browser. You get bidirectional, interruptible audio under the same auth, observability, and spend controls as the rest of the stack.

// one API, three calls generateSpeech({ model, text }) → audio transcribe({ model, audio }) → text useRealtime({ model }) → live, interruptible

A sentence, pulled from brainwaves.

Meta's Brain2Qwerty v2 decodes typed sentences from non-invasive MEG recordings at 61% word accuracy — 78% for the best participant, where most sentences come back with one wrong word or fewer. Scaling deep nets alongside a language model is narrowing the gap with surgical implants, and it needs no surgery to do it.
