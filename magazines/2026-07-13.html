The timeline lied. The replay didn't.

A new open-source Claude Code skill, clarity-session-review, formalises a hard lesson: Microsoft Clarity's event timelines are floors, not facts — watching the actual recordings overturned four headline findings in a single investigation. The skill enforces seven forensic principles for both one-off "why did user X churn?" digs and recurring session censuses, so the report you ship is the behaviour you saw, not the events you guessed.

  1. 01 Question the claim before you watch.
  2. 02 Attribute sessions to real people via database joins.
  3. 03 Triangulate replay against source and data.
  4. 04 Treat the timeline as a floor, never a fact.
  5. 05 Log every claim with on-screen coordinates.

See the hours you hand to the model.

Anthropic's new Reflect feature — in beta for Free, Pro and Max users with Memory on — turns your own chat history into a usage report. Pick a 1, 3, 6 or 12-month window and it charts what you ask Claude, which task types you delegate, and how sensitive the topics run, without exposing the conversations themselves. Built with wellness researchers, it can nudge quiet hours and asks the pointed question below.

"What's one thing you want to keep doing yourself, even if Claude could do it faster?"
