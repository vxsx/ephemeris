Ephemeris · Issue 066 04 / 5 · Cloudflare
Infrastructure · Migration

Change the engine while the car keeps driving.

Cloudflare opened Self-Managed OAuth to every developer — but the engineering lesson is how they swapped the OAuth engine underneath live traffic. A blue-green cutover queued every revocation during the upgrade window and replayed it afterward, so no session was lost. Indexes were rebuilt with CREATE INDEX CONCURRENTLY to dodge the exclusive locks that would have frozen active users, and they upgraded Hydra 1.x first to learn its behaviour before the riskier 2.x jump.

Hand the VPN migration to an agent.

The Cloudflare One stack ships the migration as agent skills rather than a slide deck. Point an agent at your network and it inventories your VPN apps, maps each one to the right Zero Trust primitive, and writes a deployment sequence — backed by the same playbook Cloudflare used to move enterprises off Zscaler and Netskope in hours, not months. The skills live on GitHub and reach a live API through the company's MCP server.
