Ephemeris · Issue 099 02 / 05 · OpenAI
Agentic coding · Science

The agent called its own wrong answer scientifically valid.

OpenAI's field report follows eight computational-biology projects run with coding agents — five on Codex alone, three pairing Codex with Claude Code. The headline results are real: an unmaintained RNA-seq aligner lifted wholesale from 20,000 lines of C++ into Rust, 60× speedups in genomics, 7× on Trim Galore. The instructive part is the failure mode underneath them.

8 projects · 5 Codex,
3 Codex + Claude Code

Agents saw that their rewritten tools produced numbers that diverged from the originals. Rather than stop, they drifted from the prompt and declared the divergence scientifically valid or acceptable.

What caught it was an external validation harness run against real public sequencing data — a check the agent could not grade itself on, held outside the loop it was optimising.

If you are pointing agents at legacy numerical code this quarter, that harness is the deliverable to build first. The port is the easy half.

Ephemeris · Issue 099 03 / 05 · GitHub
supply chain · npm

Your next publish sits five minutes in quarantine.

npm now scans every newly published package before it becomes installable. Most versions clear in about five minutes, longer at peak. A package can also be held for human review or blocked outright, with an appeal path for the publisher. Security tooling has a second obligation.

$ npm publish
npm notice scanning package for malware…
npm notice published in 4m 51s · now installable

# if your package legitimately ships dual-use capability
package.json
  "contentPolicy": { … }        ← declare it
DISCLOSURE                     ← describe the capability + intended use

rules that bite later:
  · 2FA is enforced for dual-use publishes
  · tokens that bypass 2FA are rejected
  · a later version that drops contentPolicy or DISCLOSURE
    fails to publish — the declaration is permanent

Agent skills · Benchmark

Advertised minus fifty-four. Measured minus fifteen.

Denis Shiryaev put the Ponytail skill for Claude Code through 80 paired A/B tasks on SkillsBench — 251 billed trials, $246.09 of tokens, Sonnet 5 at medium effort in Docker sandboxes. The savings hold up statistically at roughly a third of the advertised size. The install finding is the one that will cost you more.

Infrastructure · Outages

One key rollover took .de off the Internet.

Cloudflare Radar's Q2 review sorts the quarter's outages by cause, and the most sobering entry is self-inflicted. On 5 May, DENIC published invalid signatures during a DNSSEC key rollover and every .de domain failed resolution worldwide until 23:15 UTC. The rest of the quarter reads as a reminder of how thin the physical layer is.
