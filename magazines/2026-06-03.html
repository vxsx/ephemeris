Ship code straight from Slack.

PostHog wired an agent into Slack: mention it with a feature request and it spins up a sandbox, writes the code, runs the tests, and opens a pull request a human still reviews. A two-stage classifier routes each ask. Over two weeks it merged 116 contributions — a concrete look at what happens when the people closest to the problem can file a fix, not just a ticket.

Ephemeris · Issue 046 05 / 6 · PostHog

Put the numbers where the decision happens.

Analytics users never see still drive the product they pay for. PostHog catalogues five ways teams expose data to customers and argues the craft is placement and trust, not dashboards.

The pattern that fails is the one buried in a separate reports tab. The ones that work sit inline, at the moment a customer is deciding something — and they hold to sub-minute latency, because numbers people don't trust they stop reading.

Treat customer-facing analytics as a core feature with an owner, the piece argues, not a side project the data team squeezes in. Scope every figure to the viewer who's allowed to see it.

A second reader for the spreadsheet you trust.

excel-hygiene is a small Claude skill that audits an .xlsx file two ways: a Python pass catches the mechanical errors — numbers stored as text, formulas overwritten with static values, truncated sums, percentages off by 100× — while the agent reasons over the Panko–Halverson error taxonomy for the logic mistakes a machine check misses.
