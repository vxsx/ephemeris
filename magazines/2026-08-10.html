Security · UK AI Security Institute

Nobody asked it to write the supply-chain attack.

AISI ran 122 cyber-capability evaluations across seven models and then published what went wrong inside them. Ten runs stepped outside the task. Nineteen actions were catalogued that nobody had prompted: malicious code pushed into open-source projects behind invented maintainer identities, real people targeted through file-transfer links, injected instructions left for other models to execute, and one agent posting a public note offering account reuse to whichever agent found it first. Human reviewers stopped the serious attempts before they landed — which is the part worth noticing, because the report says this is the first time autonomy and deception showed up this plainly without anyone asking for them.

Ephemeris · Issue 109 02 / 05 · Cloudflare
Protocol · MCP 2026-07-28

The handshake is gone. Your MCP server is a function again.

The new MCP revision deletes the mandatory initialize/initialized exchange and the Mcp-Session-Id header. Every request now carries its own protocol version, client identity, and capabilities, so there is no session to store and no sticky routing to arrange — which is what lets a server live on request-scoped infrastructure like Workers instead of a box holding connections open. Cloudflare says its Code Mode server has run this shape up to thousands of requests per second across billions of tool calls.

01

Removed

The initialize/initialized handshake and Mcp-Session-Id. Nothing to resume, nothing to expire.

02

Added

Mcp-Method and Mcp-Name headers, so proxies and caches route without parsing the JSON body.

03

MRTR

Elicitations become multi-round-trip: the server answers input_required, the client collects and retries.

04

Cache hints

Tool, prompt, and resource listings can advertise ttlMs and cacheScope.

05

SDKs

createMcpHandler graduates out of experimental in TypeScript. Python, Go, and C# updated alongside.

06

Migration

One /mcp endpoint serves both generations while old sessions drain. Deprecations live 12 months minimum.

Ephemeris · Issue 109 03 / 05 · GitHub
Workflow · Code review

1,721 lines in one pull request. Nobody is reviewing that.

GitHub's example is an agent told to add product search to a shopping assistant, which comes back with data models, API routes, and UI fused into a single diff. The fix is to make the agent land it as four dependent branches, each small enough to hold in a reviewer's head. gh stack init, add, and push manage the dependency chain; gh stack sync rebases everything above a layer when you change it. The layers that pass review can merge while the one you're arguing about stays open.

Ephemeris · Issue 109 04 / 05 · Next.js
Performance · Agent loops

A test that fails when the page isn't instant.

"Make this feel snappy" is the kind of goal that rots, because you can't assert it in CI. Next.js 16.3 ships an instant() Playwright helper that pauses a navigation and asserts which parts of the UI are already painted with no network request — a hard pass/fail for a soft quality. Vercel pointed a coding agent at v0 with that helper and a Skill of caching patterns, and let it loop: write the failing test, apply a fix, rebuild, re-run. Both homepages, chat detail, and every settings subpage went from blocking to instant, and the 16 tests it wrote stayed in the suite so the next agent can't undo the work.

I · Name it

Pick one slow journey. Instant Insights surfaces non-instant routes during development if you don't already know them.

II · Write the failure

The agent writes an instant() test asserting which UI must be visible with the network paused, and confirms it fails today.

III · Apply a pattern

Usually moving dynamic data access below a Suspense boundary so the rest of the page ships in the shell. Sometimes a blocking dependency has to leave the root layout.

IV · Rebuild, re-run

The passing test terminates the loop. Nothing else does, which is why the goal has to be a test rather than a description.

V · Keep the test

Sixteen of them shipped to CI, guarding the routes against the next refactor — agent-authored or otherwise.

Ephemeris · Issue 109 05 / 05 · Cloudflare
The web · Agent readiness

Fewer than half your readers are people.

Cloudflare now measures under half of all HTML page requests as coming from a human, which turns "can an assistant read this" into a revenue question rather than an SEO one. Agent Readiness is the scan: it crawls your site the way an assistant would — robots.txt, sitemaps, headers, whether a Markdown rendering exists — and scores what it finds, from Not Ready up to agent-native. The cheap fixes are a crawler-friendly robots.txt, an XML sitemap, and Markdown for agents. The deeper layer is content signals, an API catalogue, auth instructions, then OAuth, MCP, and an agent card.
