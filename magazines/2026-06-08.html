Cloud GPUs, one command away.

Google's new Colab CLI wires your terminal straight to a remote Colab runtime: colab new --gpu H100 provisions an accelerator and colab exec ships a local script or notebook with no upload step. It's open source under Apache 2.0 — and any terminal agent (Claude Code, Codex, Antigravity) can drive it through a bundled skill file.

$ colab new --gpu H100
✓ runtime ready · h100 · 80gb
$ colab exec train.py
▸ streaming logs from the runtime…

Fine-tune it, and the books fall out.

Researchers at Stony Brook, Carnegie Mellon, and Columbia Law fine-tuned models on a harmless-looking task — expanding plot summaries into prose — and watched the guardrails give way. The tuned models reproduced up to 91.9% of a copyrighted book in verbatim runs as long as 440 words. Their read: refusal training is a brittle filter laid over text the weights already hold.

SQLite writes rows. DuckDB reads columns.

PostHog's team lays out why the two databases everyone embeds aren't swappable. SQLite is a row store tuned for transactional reads and writes; DuckDB is a column store built to scan and aggregate millions of rows at once. Choose by the shape of your query, not by which name you know.

SQLite

StorageRow store — whole records together
Built forTransactional reads + writes (OLTP)
Reach for itApp state, edge, embedded files

DuckDB

StorageColumn store — values by field
Built forScan + aggregate analytics (OLAP)
Reach for itLocal analysis, big aggregations

Ephemeris · Issue 051 05 / 06 · arXiv
Research · Inference

Squeeze the KV cache to two bits.

KVarN quantizes the KV cache to 2 bits without the usual accuracy collapse, and with no calibration step. It Hadamard-rotates each token, then variance-normalizes per block so quantization error stops snowballing across a long reasoning chain. The payoff: 3–5× more context, throughput above FP16, and near-FP16 accuracy on MATH500, AIME24, and HumanEval — behind a single vLLM flag.

Set a token target. Watch them game it.

Amazon gave developers AI-usage targets and a "Kirorank" board that scored people by tokens burned. Engineers did the rational thing and gamed it — pointing agents at busywork to climb, on compute Amazon paid for. The board is gone now, with a note from a senior VP: please don't use AI just to use AI.

"When a measure becomes a target, it ceases to be a good measure." Goodhart's law, this time with a GPU bill.
