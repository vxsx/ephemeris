Security · Exploit chain

From one image upload to OpenAI's internal repos in 72 hours.

Three researchers at Hacktron asked Claude Opus 4.8 to audit libheif, the library that decodes HEIF and AVIF images, and it found a heap overflow. Given the same problem soon after Opus 5 shipped, the new model had a working ARM64 exploit in three hours. The chain ran through ImageMagick into OpenAI's Discourse forum, crossed an SSO flaw, and ended in ChatGPT and Codex account takeover. The same bug reached Next.js image optimization through sharp; Vercel patched its platform in August.

Ephemeris · Issue 121 03 / 10 · TypeSafe AI · via @denissexy
New model class · API

State in. Typed odds out.

TypeSafe AI calls Jev a System One model. You define the possible answers up front: a choice among up to 255 options, a score, or true-or-false. Jev reads the shared state once, answers every question in one parallel pass, and attaches a calibrated probability to each answer. The output always matches your schema. It cannot write prose or code, and for classification, routing and triage that is the point. On Vercel's AI Gateway it reached nearly 13% of paid teams within 24 hours.

Ephemeris · Issue 121 05 / 10 · Runway · via @TochkiNadAI
Generative media · Research preview

The interface is rendered one frame at a time.

Runway's Solaris is what it calls an interface world model. You click, drag and type, and a model built on Gen-4.5 draws the next frame of the app in response, at 720p, fast enough to feel interactive. A language model decides how the interface should change; the video model renders it. With no code between design and screen, nothing gets lost in translation. Runway lists the gaps itself: text still wobbles, and long sessions lose coherence.

Ephemeris · Issue 121 06 / 10 · PostHog
Agentic coding · Playbook

From a customer agent's complaint to a merged fix in eight hours.

PostHog runs six or seven loops that find work, hand it to agents, and then check whether the fix held. Customer agents file structured feedback through the MCP; a scout groups it and routes it, and one complaint became a merged PR in under eight hours. Other loops watch Slack for bug reports, turn well-specified issues into PRs, chase metric spikes, and mine session replays for friction. The last one reads the logs after a merge to confirm the problem stopped.

Ephemeris · Issue 121 08 / 10 · AI Engineer · via @rvnikita_blog
Research · Networking

Agents send small messages, and TCP makes them wait behind big ones.

In an 18-minute talk, Stanford's John Ousterhout argues that inference and agent workloads broke an assumption TCP has carried since the 1970s. Homa, the transport his group built as a replacement, is a Linux kernel module you can run today, and he is working to get it into the mainline kernel.

Results

7–83×
lower P99 latency for short messages than TCP and DCTCP, on a 40-node cluster
≈ 2×
faster for long messages
146
its IANA protocol number

§1 The problem. Training moves huge transfers where only throughput matters, and TCP copes. Inference trades small messages: KV-cache checks, syncs between GPUs after every round. With tokens arriving milliseconds apart, one slow exchange in a thousand idles every GPU waiting on it.

§2 Why TCP. It is a byte stream, so a short message queues behind long ones, and the sender runs congestion control for a jam that forms at the receiver.

§3 Homa. Messages have lengths from the first packet, the shortest remaining goes first, the receiver grants bandwidth, and switch priority queues let short messages overtake.

Ephemeris · Issue 121 09 / 10 · OpenAI
Engineering · Postmortem

$ Two engineers and Codex moved 70M requests a second to Rust.

Habitat, OpenAI's online storage layer, started at DevDay 2023 as a Python library over Azure Cosmos DB. It now serves more than 70 million requests a second across about 40 regions. The Python service peaked above 20 million before two engineers, working with Codex, rewrote it in Rust in one quarter. The Rust service takes 95% of production traffic and is 6x more CPU-efficient and 15x more memory-efficient. The most useful part is the list of failures their load tests never caught.

Ephemeris · Issue 121 10 / 10 · Cloudflare
Engineering · Rust

Two bytes a point, 90% fewer points, 100 TB of RAM.

Cloudflare's Pingora Backend Router picks origin servers with ketama consistent hashing, which stores many points on a ring for every server. Using expected value and the coefficient of variation, the team worked out how few points they could keep before load skewed, and cut them by 90% with no appreciable error. Then they shrank each point from 8 bytes to 6. Narrowing the server index to u16 alone saved nothing, because Rust pads the struct; storing the point as a 6-byte array fixed it without #[repr(packed)].
