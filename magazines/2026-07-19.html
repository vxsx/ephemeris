Model labs · Open weights

The lab's first model ships to be forked.

Mira Murati's Thinking Machines released Inkling, an open-weight mixture-of-experts — 975B parameters total, 41B active per token — pretrained from scratch on 45 trillion tokens of text, image, audio and video. It reads all four natively, flags its own uncertainty instead of guessing, and lets you dial thinking effort up or down. It's a base to fine-tune on Tinker rather than a finished frontier model.

Ephemeris · Issue 090 02 / 04 · GitHub Engineering
Agentic coding · Practice

The code got cheap. Owning it didn't.

GitHub's Dalia Abuadas splits two costs that used to move together: producing code, now trivial for an agent, and owning it, still exactly as expensive. Her heuristic for a scoped request: stop debating in the abstract, have the agent generate a constrained patch, and read the diff as evidence. Does it touch the files you expected, does it resist testing, can a person confidently own it?

The most expensive part of a small feature request used to be writing the code. Now it's usually the meeting about whether to write it. Dalia Abuadas · GitHub

Security · WordPress

Two WordPress holes. Patch now.

WordPress disclosed two high-severity flaws: a critical unauthenticated RCE reachable through the REST API's batch endpoint when no persistent object cache is set, and a SQL injection from crafted input. Cloudflare shipped blocking WAF rules across every plan tier, and core is force-updating affected sites — but confirm your build is patched instead of assuming it happened.
