The open model caught the frontier.

Z.ai's GLM-5.2 is a 753-billion-parameter mixture-of-experts model — 40B active per token, a one-million-token context window, shipped under an MIT license on June 16. On Artificial Analysis' new AA-Briefcase test of long-horizon knowledge work it leads every open-weight model, behind only Anthropic's Fable 5 and Opus 4.8, at roughly a sixth of the cost per token.

Sandbox the agent, not your laptop.

Fly.io's field guide to running coding agents safely: hand each one a disposable, sandboxed machine so a bad command burns down a throwaway environment instead of your host. It walks through isolating risky operations, scoping what the agent can reach, and recovering when it does something it shouldn't.

Ephemeris · Issue 062 06 / 7 · Cloudflare
Dev Platform · Agents

Give your agent a throwaway account.

Cloudflare now lets an AI agent create a Temporary Account on Workers and deploy a live instance on the spot.

The signup flow is built for a human: pick a plan, confirm an email, click through a dashboard. An agent that just wants to ship a preview stalls at the first form.

Temporary Accounts skip that. The agent requests one, gets a scoped place to deploy, and pushes a running instance in seconds — handy for one-off previews, demos, and agent-generated apps that never needed a permanent home.

The account is disposable by design, so nothing long-lived is left sitting around once the work is done.

A video editor that talks to models.

Palmier is an open-source macOS editor built around AI: generate, edit, and export clips on a single timeline, with Model Context Protocol support so an agent can drive the cut.
