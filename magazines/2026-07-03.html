A coding agent built to undercut.

Z.ai shipped ZCode, a free, agent-first desktop IDE for macOS, Windows and Linux built around GLM-5.2 — its 753-billion-parameter model, released under an MIT license. Paid Coding Plans start at $16.20 a month, roughly a tenth of the premium Claude tiers it is chasing, with bring-your-own-key for other models. The pitch is long-horizon, project-level work rather than single-file autocomplete — a direct swing at Cursor, Claude Code and Copilot.

Catch the broken build before the user does.

The team behind Usage — 1.6 million downloads, a 4.7-star rating — treats every Apple release as a potential outage. The app, its menu-bar helper, a background service and the widgets each report to a separate Sentry project, and every failure is wrapped in a custom ErrorWithData so a crash carries both what broke and the unexpected payload that broke it — the tell for an undocumented API change.

Half the web isn't human anymore.

A year after Content Independence Day, Cloudflare's tally is blunt: more than half of all internet traffic is now non-human, and a market for paid crawling is forming in the gap. For every hour spent searching, only fifteen minutes now lands on the open web.

Ephemeris · Issue 074 05 / 05 · Supabase
Dev Tools · Realtime

Realtime learns to speak binary.

Supabase Realtime Broadcast can now carry binary payloads alongside JSON. Protobuf, CBOR, MessagePack or raw media frames travel over a channel as bytes instead of base64 stuffed into a JSON string — dropping the encoding tax and the serialize-on-both-ends dance. For multiplayer cursors, game state or audio, the wire finally matches the data.

before →JSON + base64 · ~1.33× bytes · encode/decode both ends
now →binary payload · 1.0× bytes · straight through
