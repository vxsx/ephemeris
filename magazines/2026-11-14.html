Ephemeris · Issue 129 01 / 10 · Anthropic
Model launch · Pricing

Fable 5.2 runs faster and costs less.

Anthropic shipped Claude Fable 5.2 and Mythos 5.2 on Monday. They are one model; Mythos sits behind Anthropic’s cyber and life-sciences verification programs. Output arrives up to 30% faster than 5.1, the list price is $8 per million input tokens and $40 per million output, and an optional fast mode runs up to 2.5× quicker at twice that. Anthropic’s own advice: keep Opus 5.5 as the daily driver and bring Fable in as advisor or orchestrator for the hard parts.

Ephemeris · Issue 129 02 / 10 · Vercel
AI Gateway · Production index

A quarter of the calls. Half a cent of the bill.

Vercel’s November AI Gateway index tracks decision models: classifiers and scorers that return a choice instead of prose, at roughly a seventieth of a language model’s cost per request. Six weeks after they arrived, they carry 26% of all gateway requests for 0.53% of the spend, and seven in ten teams running more than 10 billion tokens a month use one. If your agent spends full generations on routing and yes-or-no calls, that is the line item to move.

Ephemeris · Issue 129 03 / 10 · Anthropic · via @rvnikita_blog
Meetings · Beta

RE: Claude joins the call and writes while you talk.

Claude Meetings, in beta on Team and Enterprise plans, puts Claude into a Google Meet call as a visible participant. Ask it something out loud or in chat and it answers in writing; ask for a plan or a whiteboard and it builds one that teammates edit during the call. Afterwards the notes, action items and anything it made sit on a page in claude.ai, and you can add it to the next meeting from your calendar.

Ephemeris · Issue 129 04 / 10 · Cloudflare
Security · Threat report

ARTEX came down. Twelve thousand repos went up.

Cloudflare now tracks more than 50 families of LLM pentest orchestrators, harnesses that run an attack end to end on their own, some by handing work to Codex or Claude Code. Since ARTEX’s author pulled the original on October 8, traffic from its descendants has grown more than tenfold. In one incident, ARTEX used a compromised CI/CD API token with no IP restriction or rate limit to create Workers named artex-*.

30×

Ephemeris · Issue 129 05 / 10 · Sentry
Postmortem · Postgres

The release was named VERCEL_GIT_COMMIT_SHA.

At more than 200 orgs, a CI variable never got expanded, so every deploy landed in one release with that literal name. The worst one grew a URL index so large that a single source-map lookup took 7.4 minutes; Sentry’s query killer stopped it at 10 seconds and Symbolicator retried it twice. Bigger database instances hadn’t helped. Capping each lookup at a million rows cut CPU on the busiest host from 76% to 19%.

Ephemeris · Issue 129 06 / 10 · Fly.io
Networking · Architecture

Fly threw out the phonebook.

Every host in Fly.io’s fleet used to carry a kernel map of every Machine that had ever migrated: hundreds of thousands of entries, fed from gossip-replicated SQLite, and hosts held wildly different copies. The rebuilt 6PN private network learns a route only when a packet needs one. VXLAN flags an unknown address, a daemon asks the local database, and each host ends up holding 100 to 200 routes.

Ephemeris · Issue 129 07 / 10 · Cloudflare
Open source · Browser for agents

Greetings from 127.0.0.1:8787

Cloudflare open-sourced Kitesurf, its browser engine for AI agents, under Apache 2.0. It parses HTML, applies CSS, runs page JavaScript and renders screenshots inside Workers without a browser container, and it speaks the Chrome DevTools Protocol, so Puppeteer or your own harness connects as if to Chrome. Run it locally, then deploy it to your own account in place of the managed Browser Run API.

Having a lovely time inside Workers. The crew, all Rust compiled to WebAssembly:

  • Blitz · HTML, DOM, layout, paint
  • Stylo · CSS parsing and cascade
  • Boa · JavaScript, as a last resort
  • Linebender · text layout, 2D graphics
  • Krilla · PDF output

Ephemeris · Issue 129 08 / 10 · The Batch
Security · Linux kernel

$ 948 root bugs. 948 patches. One run.

The Batch walks through OpenAI’s GPT-6 Cyber run on the Linux kernel. Scout agents mapped the code an ordinary user can reach, analysts flagged candidates, triage agents reproduced them in a VM, exploit writers got root, and the pipeline wrote one patch per bug, at about $1,280 each. Pwn2Own pays $20,000 for a single Linux kernel exploit. For now the model goes only to selected Daybreak Red customers.

Ephemeris · Issue 129 09 / 10 · PostHog
Agents · Pricing

They charged for the PRs. Teams came for the reports.

PostHog Self-Driving, agents that read your product analytics and error tracking, write up what to fix and open pull requests if you let them, is out of beta. The beta billed $15 per PR and gave the reports away; PostHog now calls that backwards. Every run is billed, reports included. Automatic PRs start switched off, and orgs that removed their billing limit get one back at $150.

“We assumed auto-generated PRs would be the draw… once people had the beta in their hands they spent their time on the reports.”PostHog, on the beta

Research · AI R&D

Inside Anthropic, the models now improve about twice as fast.

METR spent eleven weeks inside Anthropic measuring how much AI is speeding up AI research. Its estimate: on well-specified tasks, Anthropic’s models are gaining capability about twice as fast as they did from March 2024 to October 2025, mostly because staff do R&D with AI assistance. METR found no compute, data or algorithmic bottleneck likely to slow that over the next twelve months, and it is upfront about how much it was not allowed to show.
