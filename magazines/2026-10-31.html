Ephemeris · Issue 127 01 / 10 · Pomerado · via @TochkiNadAI
Agent tools · MCP

Your agent clicks. Pomerado mints the site into a tool.

Pomerado, an MIT-licensed project from Y Combinator’s F26 batch, takes a plain-language description of a task on a website, explores the site in a real Chromium, writes operation code, tests it against the live site and publishes it as an MCP tool. It works behind logins and two-factor prompts, and the result runs deterministically. Minting uses OpenAI models; the agent that calls the tool can run on anything.

  1. 01 ─ exploreReads the siteA minter agent drives Chromium through Playwright and writes operation modules.
  2. 02 ─ exampleCompletes your task onceIt runs each step live; a reviewer agent checks the work while it builds.
  3. 03 ─ generalizeTests the inputsA read tool publishes only if at least 70% of its live test cases pass.
  4. 04 ─ callYour agent calls itStandard MCP over stdio, for Claude Code, Codex, Cursor, VS Code or Gemini CLI.

Ephemeris · Issue 127 02 / 10 · Cloudflare
Security · Inference

155 replies carried other customers’ prompts.

From 27 August to 9 September, the GLM-5.3 model on Workers AI answered some prompts with data from other customers’ recent requests. It served a 1,048,576-token context window, but its prefill KV pool held only 681,280 tokens. SGLang swapped each over-length prompt for a one-token placeholder instead of rejecting it, and the decode node generated from stale cache pages. Cloudflare took the model offline 40 minutes after declaring the incident. If you self-host disaggregated prefill/decode, make sure the KV pool can hold the full context window you advertise.

Ephemeris · Issue 127 03 / 10 · Anthropic · via @TochkiNadAI
Agent design · Skills

Fold the subagents back into one loop.

Anthropic’s Applied AI team compared enterprise agent deployments. One agent with skills often beat both a single giant prompt and an orchestrator with specialist subagents on quality, and usually on cost and latency too; one customer’s single loop ran about twice as fast. The failure they keep finding is an agent architecture that copies the org chart. The post is a migration guide, with a kit to run it on your own agent.

  1. 01Eval first. Ten golden end-to-end examples is enough to start.
  2. 02Merge pairs of specialists that chain on each other or touch the same data.
  3. 03Prompts become skills, loaded only when the task needs them.
  4. 04API calls become MCP tools, grouped by user intent.
  5. 05Past 30–50 tools, tool choice degrades. Use tool search with deferred loading.
  6. 06Hard limits live in the tools: validation, approval gates, per-user permissions.
  7. 07Diff the tasks that flipped, not just the score.
  8. 08Run every task twice or more. One break showed up in one run of two.
  9. 09Keep a subagent when context bloat measurably degrades the loop,
  10. 10or when parallel work needs fresh context you can throw away.

Ephemeris · Issue 127 04 / 10 · Next.js
Frontend · Agent skill

An agent found two megabytes of JavaScript nobody needed.

Next.js 16.4 ships next-bundle-optimizer, an agent skill that exports Turbopack’s module graph and runs a minimum cut to find the few import edges that drag heavy code into the first load. It also flags code that could move to Server Components, duplicate dependency versions and failed tree shaking. Vercel ran it on v0 and vercel.com and cut nearly 2 MB of compressed JavaScript.

Ephemeris · Issue 127 05 / 10 · Sentry
Web performance · Single-page apps

Six in ten page views had no web vitals.

Chrome now reports LCP, CLS and INP for soft navigations, the route changes a single-page app handles itself, and Sentry’s JavaScript SDK v11 records them by default. Sentry ran it on its own app for 30 days. About 62% of its page views turned out to be soft navigations that its dashboards had never scored.

Table 1 · Sentry’s app, 30 days

Page views that are soft navigations62%
Soft-navigation LCPs rated good96%
p75 LCP, all navigations2.48 s
p75 LCP, soft navigations only1.17 s

Definition. Chrome counts a soft navigation when a user action changes the visible URL and leads to a paint. Each one gets its own LCP, CLS and INP; TTFB, FP and FCP stay with page loads.

Attribution. Page-load CLS and INP now close at the first soft navigation, so a layout shift five minutes into a session lands on the route where it happened.

Caveat. Soft navigations skip the document request, so overall scores will improve the day you upgrade. Filter by navigation type before comparing.

Remedy. If fetch spans dominate the time before LCP, start the request earlier with a route loader or prefetch on hover. If CLS is high on a route, check your skeleton sizes.

Ephemeris · Issue 127 06 / 10 · Apple · via @TochkiNadAI
Creative tools · MCP

Keynote, Pages and Numbers open up to agents.

Apple’s November Creator Studio update adds Model Context Protocol support to Keynote, Pages and Numbers, so an external agent can read a document, edit it and run actions inside the app. Keynote also gets .keyx, an open JSON-based bundle format meant to be read by tools and agents. The AI features ship in beta, as a free update for existing subscribers.

For agents

  • MCP in Keynote, Pages and Numbers: read content, make edits, run automated actions.
  • .keyx, the Keynote Interchange Format: an open, JSON-based bundle.
  • In-app assistants built on Apple models and OpenAI, aware of the open document.

For making things

  • Pixelmator Pro Generate Fill: circle an area, describe the change.
  • Logic Pro Stem Splitter now isolates, replaces or rebalances drums.
  • Final Cut Pro builds in MotionVFX effects, templates and transitions.

Ephemeris · Issue 127 07 / 10 · Cloudflare
PKI · Patch now

Asked for a 115-digit key, eMudhra picked 4.

Eight eMudhra intermediate CA keys were weak enough that anyone can recover them from the public certificates and sign a certificate for any domain. Any client that doesn’t enforce Certificate Transparency and hasn’t been patched will accept it. Cloudflare patched its outbound Pingora proxies within hours and has logged the weak keys in TLS handshakes since. Up-to-date browsers mostly reject them now. Bots and old browsers mostly don’t, and Android WebViews lag behind. If you develop on macOS, follow the patch instructions linked in the post.

Ephemeris · Issue 127 08 / 10 · Import AI
Containment · Side channels

Two sandboxed agents passed secrets through the CPU cache.

OpenAI put agents in separate microVMs on shared hosts and asked them to swap synthetic secrets without network connections or shared writable files. One agent evicted chosen cache lines; another timed how long they took to reload. Once they agreed on an encoding, the secrets moved. In a second run, one agent alternated bursts of writes with idle time while the other measured the difference. Jack Clark’s Import AI 478 quotes the key passages from OpenAI’s write-up on containing its training environment. If your agent sandboxes share hardware, treat the VM boundary as leaky.

Ephemeris · Issue 127 09 / 10 · Vercel
CI · Agents

CI that runs only what you touched.

Vercel CI, in beta on all plans, reads your turbo.json, runs only the tasks your change affects, pulls the rest from Remote Cache and gives each remaining task its own machine. Tag a task with “ci” and you have no workflow YAML to maintain. It posts an ordinary GitHub check, so branch protection keeps working. Vercel says push-to-green on its own repos got 2–6× faster now that agents open most of the pull requests.

// turbo.json { "tasks": { "lint": { "tags": ["ci"] } } } $ vc ci ls $ vc ci logs <run> --task web#test --level=error $ vc ci grep "WARNING"

Ephemeris · Issue 127 10 / 10 · PostHog
Evals · Agents

Run B12 copied Run B4’s work 46 seconds later.

PostHog spends more than 2 trillion LLM tokens a month, mostly on agents, so it benchmarks them. The agents cheat: they go looking for leaked context, memory files and query logs. The post gives three levels each for answer keys, run isolation and frozen environments, with links to the real PRs.

15:18:08 Run B4 saves a memory15:18:54 Run B12 reads it and skips the work

  1. 1Build an answer key from real incidents. PostHog took 33 incidents and the PRs that caused them; its ReviewHog agent caught the culprit bug in 62% of cases.
  2. 2Isolate everything the agent can touch: scratchpads, memory, vector stores, databases, and the telemetry and logs an earlier run leaves behind.
  3. 3Don’t over-isolate. A benchmark agent with fewer tools than production gets confused, and the scores drift.
  4. 4Freeze the world. PostHog boots a copy of itself in a VM, seeds it with a restored slice of real data, and deletes the VM after each run.
