Agentic coding · Delivery

Agents wrote a third of the merges. Humans still sign every one.

Vercel put the AI SDK's issue tracker on a conveyor belt: agents in isolated sandboxes classify each report, probe it with a failing test, implement, self-score for risk, and open the pull request. A person reviews the evidence chain and approves the merge — that step never moved. Four weeks in, the open-issue count is falling for the first time in months.

Ephemeris · Issue 112 02 / 05 · Vercel
Infrastructure · Migrations

Redis answered in 1.29 ms. The replacement takes 5.13, and that exposed the real bug.

The warm pool of standby containers behind every Vercel build kept its billing records — the only ledger of which deployment gets charged — in a cache that could evaporate. Moving to DynamoDB made each query two to three times slower, which broke a supply loop nobody knew was serialised. The fix was concurrency, and the telemetry then showed the loop had been stalling under Redis all along.

Ephemeris · Issue 112 03 / 05 · Cloudflare
Bots · Trust

206 million behaviour checks in one day.

Cloudflare is retiring the single-moment bot score. Precursor watches a session end to end from the client side, and the numbers explain why: across 73,438 domains in twenty-four hours, suspicious behaviour usually surfaced mid-session, after the visitor had already been scored human. Sessions now flip between human and agentic mode, so the useful question is what this request is trying to do.

That is enough to trace a line item back to the behaviour that caused it — and enough to prove whether your prompt caching is actually earning its keep. Ephemeris · Issue 112 05 / 05 · via @TochkiNadAI
Skills · Writing

Strip the thirty AI tells, then hand it fifteen of your own posts.

A seven-step recipe for a writing skill that sounds like you rather than like a model. Start from the open-source Humanizer skill, which catalogues roughly thirty giveaway patterns, then run your own archive through an agent and have it name your sentence lengths, punctuation habits, and the words you never use. The output is one markdown file with three sections, and no code.

To
Anyone whose drafts read like everyone else's
Re
Building a voice skill from your own archive
Encl
One .md file, metadata header, allowed tools
  1. Clone Humanizer — about thirty AI-text patterns, documented.
  2. Baseline a draft through it and note what personality it strips.
  3. Collect 15–30 of your own texts; drop anything an editor touched.
  4. Have an agent describe your rhythm, punctuation, and absences.
  5. Write three sections: hard bans, encouraged, three exemplars.
  6. Feed back concrete corrections each cycle, update the file.
  7. Add a second profile per genre once the first one holds.
