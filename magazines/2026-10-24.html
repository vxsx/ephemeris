$ Two PHP RCEs. The embargo broke early.▌

PHP 8.5.12, 8.4.27, 8.3.36 and 8.2.35 fix two bugs in memory and error handling that let an unauthenticated request run code; on Apache with mod_php, one fires before any application code loads. The PHP Foundation’s account covers why a root cause spotted in 2024 sat unfixed for months, how AI-assisted audits by Calif, OpenAI and Wiz made it urgent, and how a leak plus Chainguard’s early images broke the coordinated release.

Ephemeris · Issue 126 02 / 10 · claude.dev · via @ProductsAndStartups
Agentic coding · Review

Merges doubled. The revert rate fell 40%.

Claude writes about 90% of Claude Code’s own code, so the team rebuilt review around human attention. Claude verifies its work before a PR exists; a multi-agent reviewer posts only the findings a second group votes are real; open bug or security findings block the merge; and a classifier decides how many people must approve. From June to September merged PRs more than doubled, and the share that had to be reverted fell by more than 40%.

Low riskDocs, copy, internal-only features, additive changes behind a flag. No human approval once automated and security review are green.

MediumOrdinary product changes, plus caching, the auto-updater and system prompts. One person approves.

HighThe riskiest code, and a short list of paths that always need two people. Two approve.

Who decidesA classifier reads the change and sets the tier; the author doesn’t. Lighter paths are for trusted authors only, and an agent’s approval never fills a human’s slot.

The reviewer16% → 54%Share of internal PRs getting substantive review comments once the reviewer launched.

The evalPast PRs that caused incidents, each bug confirmed by an engineer who knows that code. The reviewer runs against the set every day.

Ephemeris · Issue 126 03 / 10 · Cloudflare
Dev tools · TypeScript

TypeScript, ported to Rust. Up to 8× faster.

Cloudflare and VoidZero, with Max Schwenk of Owner.com, are porting the TypeScript compiler to Rust in close collaboration with the TypeScript team, incubated in the Oxc toolchain. They say it is a faithful port and the TypeScript team keeps control of the language. The bigger reason for Rust is WebAssembly: no garbage collector rides along in the binary, so a full checker fits in a Worker or a browser tab. Experimental today via npx tsrs.

8×faster than TypeScript 7.0, same number of type-check workers

RE:The skill is the memory.

PostHog’s Andy Maguire loaded a skill in 78% of his 578 agent chats over 28 days and had the agent update one in 47%. Ephemeris · Issue 126 05 / 10 · Cloudflare
Cost · Inference

A review cost $2.43. Now it’s 77¢.

Cloudflare’s internal AI code reviewer doubled in cost from April to August without an architecture change, as tokens per review tripled and pricier models moved in. A month of measured fixes took 68% off. The worst leak: first calls found a cached prefix only 14–26% of the time, because the shared prompt and per-repo details sat behind one cache breakpoint. Splitting it, reading files in parallel and running Opus 5.5 at medium effort did much of the rest.

Ephemeris · Issue 126 06 / 10 · Pixel Path on GitHub · via @TochkiNadAI
Creative · Claude Code skill

Type two places. Drive the real road in pixels.

Pixel Path is a Claude Code skill by Jon Wheatley. Ask for “a pixel path from Bath to Bristol” and it routes the trip, bakes the buildings, land cover and landmarks along it from OpenStreetMap and elevation data, generates scenery with RetroDiffusion, checks its own frames with screenshots and hands you an index.html to scroll through. Only the art costs money, and it quotes before it spends.

Greetings from the road. Every building facing it stands on its real footprint, the hills come from a 61 × 61 km height grid that allows for the Earth’s curvature, and the signs are drawn by code so the names are exact. Scroll to speed up; keep going the other way to reverse.

Open weights · Model

Open weights, 0.7 points behind Opus.

Moonshot’s Kimi K3.1 Pro is a 3T-class open-weight model with a 1M-token context. On Terminal-Bench 4.0 it scores 65.7%, against 66.4% for Claude Opus 5.5 and 58.2% for GPT-6 Astra, by Moonshot’s own count. It is in the Kimi API and apps now, alongside a Highspeed variant that generates 2–3× faster; the full weights are due by 4 November.

Ephemeris · Issue 126 08 / 10 · Anthropic
AI tool · Agent safety

It works while you’re away. It still asks before it pays.

Claude Duet, a research preview for US Pro and Max subscribers, is a proactive agent on a cloud computer wired to your connected apps: it sends a morning brief and keeps running routines after you close the app. Anthropic’s safety write-up is the part to read if you build agents. Credentials never reach the model, a classifier outside the model checks each action against your intent, and approvals are tuned against click-through fatigue.

“If something that looks like Claude Duet asks for your password anywhere else, it’s not legitimate.”Claude Duet safety, privacy and security · 23 Oct
Always asksPaying or sending money, deleting an order, creating an account. None of these can go on “don’t ask me again.”

Let the judge click the app.

LLM judges grade agent-built apps by reading the code and running tests; people grade them by using them. In Interaction-as-a-Judge, by Wayne Chi, Ion Stoica, Chris Donahue and colleagues, a computer-use agent operates the app instead. It agrees with human preferences more often, catches more unmet requirements, and as a repair loop it fixes far more of what’s broken. The team released 6,858 app pairs with human preferences and agent traces.

Ephemeris · Issue 126 10 / 10 · Vercel
Dev tools · Agents

Close the lid. The turn resumes from the log.

Vercel’s open-source durable-harness wraps Claude Code, Codex, Pi or OpenCode so a session survives a crash or a function timeout. Before every model or tool call it records an intent, and after it the outcome; a queue message backstops the whole turn. The log can live on Vercel, in local files, or in your own Postgres, MongoDB, Redis or Turso.
