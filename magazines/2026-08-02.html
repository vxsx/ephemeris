Ten stuck problems, and a certificate for each one.

An internal version of OpenAI's Astra model produced proofs for ten problems in mathematics and theoretical computer science that had seen no progress on the main result for at least a decade — among them the existence of non-sofic groups, a disproof of Connes's rigidity conjecture, and sphere-packing bounds pushed down to the Cohn–Elkies threshold. Each result ships with a Lean 4 formalisation in a public repo, so the argument can be machine-checked rather than taken on trust. What is missing from the write-up is the denominator: how many problems were attempted, and what the prompts were.

Ephemeris · Issue 103 02 / 05 · Claude Code
Agentic coding · Workflow

Make it run your check before it says done.

A verification loop is the cycle where an agent runs tests, linters or custom checks against its own output and fixes what fails before moving on. Claude Code ships a /verify skill and hooks into your toolchain, but the part worth your afternoon is converting the checks you still run by hand into skills — a markdown file under .claude/skills/ with frontmatter and instructions written the way you'd hand them to a new teammate. The examples are the project-specific rules a generic linter will never know: every error log carries a request ID, and no log ever contains a request body.

Ephemeris · Issue 103 03 / 05 · GitHub
Code review · MCP

Your reviewer can finally read your standards.

Copilot code review now supports agent skills and MCP servers on every plan — Pro, Pro+, Business and Enterprise. Put a SKILL.md in a subdirectory of .github/skills and the reviewer argues from your team's conventions instead of general advice; point it at an MCP server and it pulls context from the issue tracker, docs site or service catalogue you already run. Every MCP call made during a review is read-only, and the GitHub and Playwright servers are on by default. Anyone who wired this up during the public preview changes nothing.

Ephemeris · Issue 103 04 / 05 · GitHub
Supply chain · npm

The token that skipped 2FA just lost its rights.

npm granular access tokens set to bypass two-factor authentication can no longer create or delete tokens, change package access, maintainers or trusted-publishing config, or manage organisation and team membership. Those operations now demand an interactive 2FA challenge. Publishing still works from such a token — until January 2027, when direct publish goes too. If your CI publishes with a bypass token, the migration is to trusted publishing over OIDC, or to staged publishing, and you have five months. GitHub PATs, GitHub App tokens and GITHUB_TOKEN in Actions are untouched.

Agent tooling · Open source

One CLI, and the agent stops paying to read the web.

Agent-Reach gives an agent a single command line for reading and searching Twitter/X, Reddit, YouTube, GitHub, Bilibili and XiaoHongShu, without a platform API bill behind any of them. Each site gets a first-choice backend and a fallback — twitter-cli, then OpenCLI, then bird — layered over yt-dlp, Jina Reader and Exa, with an agent-reach doctor command that reports which paths actually work on your machine right now. It sits at 64,100 stars and was last updated on 25 July.
