Ephemeris · Issue 080 04 / 6 · Cloudflare
Infra · Distributed systems

Consensus without a leader.

Cloudflare's Meerkat swaps leader-election for QuePaxa: any replica can drive agreement, and concurrent proposals cooperate instead of colliding. Across 330+ data centers where latencies swing unpredictably, that removes the single timing-out point Raft depends on.

10×throughput vs. Raft & Multi-Paxos under a hostile network

Ephemeris · Issue 080 05 / 6 · GitHub

Docs that write themselves, then wait for you.

GitHub's Agentic Workflows are GitHub Actions with an AI model as the work-item processor — authored as markdown with an English prompt and compiled to constrained Actions. Aspire's pr-docs-check turns every merged feature into a drafted, correctly-branched docs PR. Nothing auto-merges.

on: merge → main / release/* ▸ read the product diff ▸ decide if docs are needed ▸ draft in the house style ▸ resolve target branch (milestone → release) ▸ open DRAFT PR → route to the feature's reviewer

Dev tools · Self-hosted

An agent you run by messaging it.

right-agent turns a Telegram chat into an agent that uses your own Claude subscription — no third-party API keys. Every agent runs in its own sandbox; every credential lives outside it, so a compromised run can misuse a tool but never walk off with a token. Rust, self-hosted, one command to start.

$ curl -LsSf https://raw.githubusercontent.com/onsails/right-agent/master/install.sh | sh $ right up ▸ agent online · telegram bound ▸ sandbox: isolated · credentials: external ▸ v0.4.2 · try /mcp · /providers █
