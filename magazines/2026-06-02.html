Four hours to reboot a server. Now it's minutes.

After a firmware update, Cloudflare's core units took up to four hours to come back. The slow path was UEFI and iPXE sitting through timeouts that never needed to fire. Delete the waits and reboots drop to minutes — a reminder that if you run bare metal, the boot path itself deserves a profiler, not just the OS on top of it.

An agent read the query plan and found a three-year-old bug

PostHog pointed an autoresearch agent at ClickHouse and it surfaced a defect that had hidden since 2023: timezone-wrapped timestamp comparisons that blocked partition pruning, so every affected query scanned far more data than it needed. Remove the wrapper and granule scans fall 62%. The signal worth keeping: agents are now good enough to audit the slow paths humans stopped looking at.

LLM Ops · Playbook

You shipped the LLM feature. Now watch it.

A day-one observability kit for small teams who just put their first AI feature in front of users — no platform team required. Three setups, in the order they'll save you:

  1. Trace every model call. Inputs, outputs, latency, the prompt version — so a bad answer is a row you can open, not a story a user tells you.
  2. Track cost with alerts. Per-feature token spend with a threshold, so a runaway loop pages you before it pages finance.
  3. Capture the LLM-specific failures. Tool-call errors and token-limit blowups don't throw like normal exceptions; instrument them on purpose.
