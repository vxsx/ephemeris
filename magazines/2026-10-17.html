Ephemeris · Issue 125 01 / 10 · Anthropic Engineering
Dev infra · Agentic coding

Git couldn’t keep up with Claude.

Merges into Anthropic’s monorepo rose from about 2,500 a day in May to more than 30,000 in September, and CI ran 25 million checkouts a day against nearly 100 GB of history. Seven engineers built Scion, version control for clients that are always online: the server owns history, merges and blame, and each job fetches only the files it reads. Anthropic offers its server-side RPC, cache tiers and sparse checkouts as ideas to carry back to git and the forges.

Ephemeris · Issue 125 02 / 10 · Mistral · via Import AI
AI tools · Open weights

Open weights for the people who patch.

Mistral Large 4 is a mixture-of-experts model with about a trillion parameters, 52 billion active, in public preview on Mistral Studio at $1.36 in and $4.18 out per million tokens. It scores 82% on a test that asks a model to reproduce a real vulnerability and then patch it, the best result among publicly available models; Mistral says several closed models score near zero there because they refuse. Import AI’s caveat: it is the strongest Western open-weight model and still trails the leading Chinese ones.

“Weights drop end of this month.”

Mistral, announcing Large 4 on 6 October. Hosting includes a European deployment Mistral runs end to end; the license is not yet named.

Ephemeris · Issue 125 04 / 10 · Cloudflare
Postmortem · Databases

One query in 100,000 came back empty.

Hyperdrive pools database connections for Cloudflare Workers and caches query results, and its MySQL beta failed on about 0.001% of requests, only where caching was on. The cause was a capability flag: the mysql2 driver can’t read CLIENT_DEPRECATE_EOF, so the node beside the Worker rewrote result bytes while the node beside the database did not, and both wrote their own encoding under the same cache key. If you cache wire bytes behind a protocol translator, this is the bug to look for.

FRAME 01

Hyperdrive talks to the origin with CLIENT_DEPRECATE_EOF on. The Worker’s mysql2 driver can’t, so result sets must end the old way.

FRAME 02

The client node translates for the Worker. The endpoint node keeps the origin’s bytes. Both cache under one key.

FRAME 03

Each node reads the other’s bytes: an untranslated answer, an early EOF, or a hang.

FADE OUT

Store one canonical encoding, whoever writes it. Client connection success: 99.99%. MySQL is now GA.

“the difference between beta and GA is just 20 bug fixes in a trenchcoat.”

Ephemeris · Issue 125 05 / 10 · ibragim-bad · via @seeallochnaya
Agentic coding · Evals

Your old sessions are the eval set.

Ibragim went through about 1,270 of his own Claude Code, Codex and Pi sessions, kept ten tasks that a script can check, and ran agent setups on them three times each. On GPT-6.1 Sol both the lightweight Pi agent and native Codex solved every task, and Pi did it for half the money. His skill, evals-from-sessions, walks your agent through the same pipeline into Harbor tasks, and stops for your approval on the candidate list, the spec and the finished task.

  2. 2

  3. 3
    Seal

    Package a Harbor task with no future commits, reference diff or visible tests to peek at.

  4. 4

    A no-op fails, the oracle passes, a near miss fails, a different correct fix passes.

Ephemeris · Issue 125 06 / 10 · GitHub
Architecture · Privacy

Star history, without the stargazers.

Star-history tools drew their charts by paging through every account that starred a repository, 100 at a time, through an endpoint that also let spam and phishing scrapers harvest usernames. GitHub now limits stargazer lists to a repository’s admins and collaborators and has added a star-history endpoint that returns daily counts with no user data, up to 30 weeks per call. If your dashboard reads the old list, it gets an empty response or a 403.

Ephemeris · Issue 125 07 / 10 · Vercel
Security · Sandboxes

A packet from inside the sandbox reached the host.

Vercel’s $1M bounty for escaping Vercel Sandbox drew 1,285 reports in two weeks and paid out $242,000. On day three Paulos Yibelo found a flaw in the Linux kernel’s networking stack: crafted packets from inside a microVM leaked host memory in production, and on matching KVM and Firecracker machines crashed the host or ran code on it. CVEs are pending, and the same kernel layer isolates tenants at most large clouds. If you run sandboxes for agents, the section on what Vercel stopped trusting is the part to copy.

Ephemeris · Issue 125 09 / 10 · Cloudflare
Dev tools · Deploy

Your imports are the infra config.

VoidZero, the Vite company that joined Cloudflare, released Void: an open-source SDK, CLI and self-hostable platform shipped as one npm package and Vite plugin. Import void/db and you get a local database in development and D1 on deploy; void/ai wires up AI Gateway. void deploy builds, migrates, provisions and ships, and Void Platform lets a company give people a place to ship internal apps without a Cloudflare account per project.

$ npm install void
# add the Void plugin to vite.config

import … from "void/db"  // D1 on deploy
import … from "void/ai"  // AI Gateway

$ void deploy
  build · migrate · provision · ship
$ void connect <platform-url>
  ship to your own Void Platform

“Void turns a Vite app into a full-stack Cloudflare Workers app.”

Works next to React Router, SvelteKit, Nuxt, TanStack Start and Astro. Auth through Better Auth; the platform needs Workers for Platforms, R2 and a Postgres database.

Ephemeris · Issue 125 10 / 10 · Next.js
Security · Patch today

Two unauthenticated RCEs. Patch to 16.4.1.

The 14 October out-of-band release fixes two critical remote-code-execution bugs and one high-severity denial of service, all traced to upstream dependencies. The first hits App Router apps on Cache Components, which create-next-app has switched on by default since 16.4, and has no workaround. The second sits in image optimization of SVGs on glibc Linux, through sharp.
