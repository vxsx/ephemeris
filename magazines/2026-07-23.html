Prove the cheaper model is actually cheaper.

Open weights are surging and every pipeline is a migration candidate — but a single eval run flatters whichever model got lucky. oss-migration-eval, a Claude Code skill from Bayram Annakov, decides the swap with statistics: human-validated golden datasets seeded with trap cases, provider-pinned sweeps across several seeds, deterministic grading, and an optional blind panel for subjective work. It reports cost saved against accuracy lost, with confidence intervals instead of vibes.

Observability · Logging

A log is an event, not a sentence.

Sentry's field guide treats a good log as a small, queryable event: a stable name in domain.action form, dynamic values pushed into flat dot-notation attributes, and every value kept to a primitive. Do that and each field becomes something you can filter, group, and alert on at 3am — no regex archaeology across free-text messages.

# interpolated into the message → nothing to query log.info(f"charged {user} ${amt} for {plan}") # stable name + flat primitive attributes → a table log.info("payment.capture", user_id=u.id, amount_cents=4200, plan="pro", result="ok")

Agentic AI · Multi-agent design

Give your agents separate rooms.

The point of a multi-agent council is disagreement. But hand the members shared file access or a shared context and they read each other's reasoning first — the diversity you built the panel for collapses into groupthink. Bayram Annakov's /council skill fixes it in the architecture: each persona evaluates inside its own sub-agent, and the evaluator runs in a separate context window that never sees the generator's chain of thought.
